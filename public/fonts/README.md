# Folder Font Kustom SakuPas

Letakkan file font web berikut di folder ini:
- `Univers.woff2` (atau `Univers.woff`) — Digunakan untuk wordmark brand, heading halaman, heading bagian, metrik finansial, dan angka penting.
- `ShandonSlab.woff2` (atau `ShandonSlab.woff`) — Digunakan untuk body text, deskripsi, navigasi, tombol, formulir input, dan tabel transaksi.

Aplikasi telah dikonfigurasi dengan `@font-face` di `src/index.css` serta fallback tipografi yang elegan jika file font belum dimuat.
